Automations

Automations are scheduled or event-driven actions on tasks. See the writing automations tutorial for an end-to-end walkthrough.

Trigger types

  • cron — a cron expression schedules the action. PRD §8.4.
  • event — reacts to a task event (see events). PRD §8.4.3.

Action shape

Actions call a whitelisted system method (e.g. tasks.bulk_update) with a Jinja-rendered payload. Secrets are referenced by name and resolved server-side. ARCH §11.
