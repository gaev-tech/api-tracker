Quickstart

Zero to your first task in under a minute.

≈ 1 MIN READ FOR: HUMAN OR AI AGENT
01 Install

The recommended channel is pipx — it isolates the install and exposes the clite binary on your $PATH. 

$ pipx install clite
$ clite version

Other channels (Homebrew, APT, npm wrapper) land in M4.B. See installation.

02 Log in

Magic-link login. The CLI asks the server to email you a link, then waits for you to click. 

$ clite login --email me@example.org
03 Create a task

Even single-task create goes through the bulk API. Pass a JSON array. 

$ clite create tasks --bulk '[{"title":"First task"}]'
04 Read it back

Filter with RSQL; me is a built-in literal for the current user. 

$ clite get tasks --filter 'status=="open";assignee==me'
