Quickstart

Get the clite daemon watching your first repository — and tracking your first task — in under a minute.

≈ 1 MIN READ
UPDATED 2026-06-13
01
Install the binary

clite ships as a single static binary named clt. Install it with your package manager of choice:

install.sh
# Homebrew
$ brew install clite
# or curl
$ curl -fsSL get.clite.dev | sh
Note
The binary runs a lightweight background daemon. It uses filesystem events — no polling — so it costs nothing while idle.
02
Initialize a workspace

From the root of any repository, link it to clite:

$ clt init
✓ workspace linked · .clt/ created
✓ daemon watching 1 path
03
Add your first task
$ clt add "ship the docs" --due fri --flag high
✓ #4012 created

Command Reference

Command
Description
clt add
Create a task with optional due date and flags.
clt ls
List tasks. Filter with --open / --due.
clt done
Close one or more tasks by id.
clt sync
Push and pull task state across machines.
!
Danger
clt reset --hard erases all local task state and cannot be undone. Sync first.
